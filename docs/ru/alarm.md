# Будильник и Сторож

[English version](../alarm.md)

Будильник, который проверяет, что вы действительно встали, а не нажали «отложить» сквозь сон.
Он не выключается кнопкой: замолкает, только когда вы **наберёте фразу** на компьютере (или
ответите на пример в Telegram, если его подключить), и потом ещё несколько раз проверит,
не уснули ли вы снова.

После установки будильник и Сторож **выключены**.

---

## Быстрый старт

1. Нажмите **Super+Alt+F** — откроется окно **Discipline** на вкладке **Alarm**.
2. **Пробел** — включить будильник.
3. **h** / **l** — сдвинуть время на 15 минут, или **i** и ввести время (`06:30`).
4. **t** — пробный звонок на 10 секунд, **s** — остановить.
5. **q** — закрыть. Всё сохраняется сразу.

То же из терминала:

```sh
wake-alarm on
wake-alarm default 06:30     # время для всех дней без своего
wake-alarm status            # включён ли, ближайший звонок, план
wake-alarm test              # пробный звонок на 10 секунд
```

---

## Что происходит утром

Пусть будильник стоит на **07:00**.

| Время | Что происходит |
|---|---|
| 06:55 | **Проверка.** На всех мониторах окно с короткой фразой. Наберите её и Enter — это одно подтверждение. Звука пока нет. |
| 07:00 | **Звонок**, если не подтвердили. Громкость начинается тихо и за две минуты доходит до полной — через динамики и через то, что сейчас играет (наушники). |
| 07:08 → 07:10 | Проверка за две минуты до следующего звонка, потом звонок, если не ответили. |
| 07:18 → 07:20 | То же. |
| 07:28 → 07:30 | Последний звонок, длится до 30 минут. |

**Два подтверждения подряд — утро закончено.** Подтвердили в 06:55 и в 07:08 — будильник так
и не зазвонит.

Звонок замолкает, только если набрать его фразу (или ответить на пример в Telegram). Фраза
каждый раз новая, выучить нельзя. Фразы короткие, русские и английские, иногда смешанные —
раскладку приходится переключать посреди фразы, это тоже будит.

**Контрольная проверка.** Примерно через 50 минут после первого подтверждения — ещё одна
тихая проверка. Не ответили за 5 минут — снова звонок (до 30 минут). Это на случай «встал,
подтвердил и лёг обратно».

Если в момент звонка компьютер спал и проснулся в пределах получаса — будильник всё равно
зазвонит.

Пока идёт утренняя серия, сегодняшний будильник нельзя ни изменить, ни выключить — ни в
Discipline, ни из терминала. Планируйте с вечера.

## Планирование по дням

У каждого дня может быть своё время; у остальных — время по умолчанию.

```sh
wake-alarm default 07:00            # обычное время
wake-alarm set 06:00 2026-10-12     # один день раньше
wake-alarm set 06:00                # только ближайший звонок
wake-alarm skip 2026-10-11          # в этот день не звонить
wake-alarm off                      # выключить совсем
```

В Discipline (вкладка Alarm):

| Клавиша | Действие |
|---|---|
| j / k | по дням |
| h / l | −15 / +15 минут |
| − / = (или Ctrl+X / Ctrl+A) | −1 / +1 час |
| i, Enter или цифра | ввести время |
| x | пропустить день |
| dd | вернуть день к времени по умолчанию |
| yy / p | скопировать / вставить время |
| u / Ctrl+R | отменить / вернуть |
| Пробел | будильник вкл / выкл |
| t / s | пробный звонок / стоп |
| ? | справка |

Клавиши работают при любой раскладке.

Чтобы сдвинуть режим сна, двигайте время на 15–30 минут раньше раз в день-два, пока не
дойдёте до цели, а дальше пусть работает время по умолчанию.

## Сторож

Сторож — для дней, когда нельзя уснуть днём. С **06:00 до 21:00** примерно раз в 45 минут он
спрашивает «не спите?» — то же окно с фразой и, если не ответить, тот же звонок.

Пока вы за компьютером, он молчит: проверка приходит, только если 30 минут не было ни клавиш,
ни мыши, и не чаще раза в 45 минут. В день с будильником Сторож начинает работу после
утренней серии.

**Включить:** Настройки (**Super+/**) → **Config** → **Сторож**, или

```sh
wake-alarm watch daily on
```

**Выключить нарочно сложнее**, чтобы не сделать это в полусне:

- насовсем — Настройки → Config → Сторож: спросит пароль от системы и причину;
- на один день — в Discipline (клавиша **o** на вкладке Alarm), с подтверждением;
- из терминала — причина обязательна:

```sh
wake-alarm watch daily off --reason "отпуск"
wake-alarm watch skip 2026-10-12 --reason "дорога"
wake-alarm watch skip off 2026-10-12      # вернуть день
```

Каждое выключение пишется в журнал со временем и причиной:

```sh
wake-alarm watch log
```

Разовый Сторож на один день со своими часами:

```sh
wake-alarm watch 2026-10-12 08:00-20:00 30    # проверка каждые 30 минут
wake-alarm watch                              # список
```

## Telegram (по желанию)

Будильник может писать и в Telegram: каждая проверка присылает пример (вроде `47 + 38`).

1. Создайте бота у [@BotFather](https://t.me/BotFather), скопируйте токен.
2. Узнайте id своего чата (например, у [@userinfobot](https://t.me/userinfobot)).
3. Создайте файл `~/.config/wake-alarm/env`:

   ```
   TOKEN=123456:ABC...
   OWNER=123456789
   ```

Этого хватит, чтобы **получать** примеры. Чтобы **подтверждать ответом**, вашему боту нужен
небольшой обработчик, который передаёт ответ дальше:

```sh
wake-alarm tg-code "85"      # код выхода: 0 принят, 1 неверно, 2 ничего не ждём
```

Когда такой обработчик работает, добавьте в тот же файл `REPLY=1`. Без него сообщения просят
подтвердить на компьютере.

## Звук

```sh
wake-alarm sound t3        # по умолчанию: 520 Гц, сериями по три
wake-alarm sound classic   # мягкий стандартный звонок freedesktop
```

`t3` — сигнал пожарной тревоги; в исследованиях он будил из глубокого сна лучше обычных
сигналов. Громкость динамиков после звонка возвращается, даже если будильник убили.

## Все команды

```
wake-alarm status                        вкл/выкл, ближайший звонок, план
wake-alarm on | off
wake-alarm default ЧЧ:ММ
wake-alarm set ЧЧ:ММ [ДАТА]
wake-alarm skip [ДАТА]
wake-alarm test [СЕКУНДЫ]                пробный звонок (10 с)
wake-alarm stop                          остановить пробный звонок
wake-alarm series                        как прошло последнее утро
wake-alarm test-series [К] [--dry]       вся серия ускоренно (К секунд на «минуту»)
wake-alarm woke [ЧЧ:ММ] [ДАТА]           записать подъём вручную («-» — стереть)
wake-alarm sound [t3|classic]
wake-alarm tg-code ТЕКСТ
wake-alarm watch ДАТА ЧЧ:ММ-ЧЧ:ММ [МИН]
wake-alarm watch off [ДАТА]
wake-alarm watch daily [on | off --reason ТЕКСТ]
wake-alarm watch skip [ДАТА] --reason ТЕКСТ | watch skip off [ДАТА]
wake-alarm watch log [N]
```

Окно Discipline открывают команды `discipline`, `routine` и `alarm`.

## Файлы

| Путь | Что |
|---|---|
| `~/.config/hypr/state/wake-alarm.json` | расписание и настройки |
| `~/.config/wake-alarm/env` | Telegram (по желанию) |
| `~/.local/state/jarvis-wake/` | состояние серии, журналы, журнал Сторожа |
| `~/.config/systemd/user/wake-alarm.timer` | раз в минуту зовёт `wake-alarm check` |

Если не происходит вообще ничего — проверьте таймер:

```sh
systemctl --user status wake-alarm.timer
systemctl --user enable --now wake-alarm.timer
```
