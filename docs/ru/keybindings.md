# Все сочетания клавиш

[English version](../keybindings.md)

Полный список биндов из `binds.kdl`, сгруппированный так же, как в самом файле. Для
первого знакомства достаточно таблицы «Первые клавиши» в README — здесь всё, вплоть
до мелких привычек, перенесённых из Hyprland. **Mod** — это Super (клавиша с лого).
Живой список прямо в системе: **Super+Shift+/**.

---

| `Ctrl + Shift + ]` | картинка в картинке |

### Служебное

| Клавиши | Действие |
|---|---|
| `Mod + Shift + /` | показать все сочетания (на русской раскладке не нажать — физическая клавиша там шлёт `.`, используйте дубль ниже) |
| `Mod + Shift + Period` | показать все сочетания (дубль для русской раскладки) |
| `Mod + Escape` | отдать все клавиши окну (вкл/выкл) |
| `Mod + Shift + E` | выйти из niri |
| `Ctrl + Alt + Delete` | выйти из niri |
| `Alt + F4` | меню питания |
| `Mod + Shift + \` | выключить мониторы |
