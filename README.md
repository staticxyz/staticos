# staticOS

A pixel / retro-styled [niri](https://github.com/YaLTeR/niri) desktop for Arch Linux, where every
color comes from the current wallpaper.

Waybar on top, an optional Windows XP-style taskbar at the bottom, a set of small GTK3 panels and
popups written in Python, and [matugen](https://github.com/InioX/matugen) templates that push the
wallpaper palette into the bar, terminal, notifications, GTK/Qt apps, the cursor and more.

## Features

**Bars & panels**
- Waybar with several looks (floating, edge, compact, islands, bottom, transparent), adjustable
  rounding and margins, top bar modes (always / on hover / off).
- Bottom panel: nothing, a dock, or a Windows XP-style taskbar with a Start button and Start menu.
- Bar modules: workspace ribbon map, window title, XP-style taskbar buttons, keyboard layout with
  Caps Lock indicator, now playing + synced lyrics, cava visualizer, Bongo Cat, privacy
  indicators (mic / screen sharing), battery, pomodoro, recorder status.
- Custom icon fonts for the bar are generated by scripts (`build_*_font.py`).

**Desktop widgets** (`desktop_widgets.py`, `desktop_widgets_extra.py`)
- Clock, date, calendar, timer, pomodoro, weather (wttr.in), system monitor, player,
  screen time, matrix rain, visualizer, fastfetch, Doom fire, Game of Life and more.
- Right-click desktop menu in the spirit of Windows XP.

**Notification center & control center**
- swaync themed from the wallpaper, with an alternative "Noctalia-like" look (`notif-look`).
- Control center with quick toggles, Wi-Fi, Bluetooth, brightness, recent notifications.

**Popups**
- Calendar, volume, microphone, Wi-Fi, Bluetooth, energy / battery, player, memory usage
  per application, calculator + offline translator (NLLB).

**Window management (niri)**
- Alt+Tab switcher, per-app volume keys, column helpers, a "pocket" scratch workspace, hot corners, workspace insert,
  workspace switch animation presets (`ws-anim`), pixel mosaic open/close effect.

**Screenshots & recording**
- Screen recorder for GIF / video / sticker (optional background removal), red frame around
  the recorded area, pause/resume, instant replay buffer (`replay`).
- Annotated screenshots, screenshot pinned to a floating window, OCR to clipboard.

**Screensaver & lock**
- Own screensaver and a custom lock screen on gtk-session-lock (with hyprlock as fallback),
  hypridle-based dim / lock / suspend, SDDM astronaut theme switcher.

**UI sounds**
- Short sounds for shell events: a synthesized retro set (`ui_sound_retro.py`) or your own
  Windows XP set (not included, see Notes).

**Settings app** (`settings_app.py`, `Mod+/`)
- One window for bar, panels, fonts, cursor, wallpaper blur, night light, lock screen, terminal
  shaders, widgets and more.

**Theming**
- Wallpaper picker (`Mod+W`) and waypaper, matugen palette applied on every change
  (`theme_changer.sh`), with `theme_doctor.py` to check the whole color chain.
- Recolored pixel cursor, Papirus folder colors, kitty shaders (CRT, cursor trails), terminal ANSI
  colors, btop, cava, fastfetch, Telegram, Spotify (spicetify), Obsidian, VS Code, LibreWolf.

**Terminal tools** (`~/.local/bin`)
- `pomo` (pomodoro), `timer`, `jclock`, `tclock`, `tmatrix`, `jtype` (typing trainer),
  `jtetris`, `brrt`, `appmem`, `picker` (color picker), `barfix`, `ws-anim`, `power`, `fan`.

## Install

> These are personal dotfiles. Read through them before copying, and back up your own configs first.

```sh
# 1. Back up what you have
for d in niri waybar swaync kitty rofi matugen eww waypaper hypr; do
  [ -e ~/.config/$d ] && mv ~/.config/$d ~/.config/$d.bak
done

# 2. Get the files
git clone https://github.com/staticxyz/staticos ~/staticos
cd ~/staticos

# 3a. Copy them...
cp -r .config/. ~/.config/
cp -a .local/bin/. ~/.local/bin/

# 3b. ...or symlink them with GNU Stow
stow --target="$HOME" .

# 4. Build the small X11 clipboard helper (used by x11-clip-bridge)
gcc -O2 -o ~/.local/bin/x11-clip-events .local/src/x11-clip-events/x11-clip-events.c -lX11 -lXfixes

# 5. Generate the palette once, then the retro UI sounds and bar fonts
~/.config/hypr/scripts/theme_changer.sh /path/to/wallpaper.png
python3 ~/.config/hypr/scripts/ui_sound_retro.py
python3 ~/.config/hypr/scripts/build_bar_icons.py

# 6. Optional user services
systemctl --user enable --now night-schedule.timer gtk-guard.path
```

Then log out and back in to niri (or run `niri msg action load-config-file`).
Make sure `~/.local/bin` comes first in your `PATH`.

Things you will most likely want to adjust:
- monitors in `.config/niri/cfg/outputs.kdl` (and `open-on-output` rules in `window-rules.kdl`);
- default apps in `.config/niri/cfg/binds.kdl`;
- the Obsidian vault path in `.config/matugen/config.toml`.


## Notes

- **Scripts live in `~/.config/hypr/scripts`** for historical reasons: the setup started on
  Hyprland and moved to niri. Most scripts work through a small compositor layer (`wm.py`).
- **Legacy Hyprland config.** `~/.config/hypr/*.lua` and `hyprland`-specific scripts are kept for
  reference and are no longer the main setup. `hypridle.conf` and `hyprlock.conf` are still used.
- **Windows XP sounds are not included** (they belong to Microsoft). To use the XP sound set, put
  your own `.wav` files into `~/.config/hypr/sounds/xp/`. The retro set is generated by
  `ui_sound_retro.py` into `~/.config/hypr/sounds/retro/`.
- **Generated files are not tracked:** `waybar/config-niri.jsonc` and `waybar/style-niri.css` are
  built by `.config/niri/scripts/waybar_niri.py`; palettes go to `~/.cache/matugen`; runtime state
  goes to `~/.config/hypr/state`.
- **Fonts.** The UI font family `PxPlus HP 100LX 6x8 Jarvis` is a locally patched copy of
  `PxPlus HP 100LX 6x8` (wider em dash) and is not distributed here; fontconfig falls back to the
  next font in the list. "Jarvis" in file, font and theme names is just a project name.
- **Hardware-specific bits:** `fan`, `power`, `kbd_colors.py`, `razer_*` and the udev rule target
  one specific laptop and keyboard. They are harmless elsewhere but will not do anything useful.
- **Language.** Most UI strings and code comments are in Russian.
- **Skeet look icons are not included** (they were cut from screenshots of a third-party menu).
  Put your own 48×48 alpha masks into `~/.config/hypr/scripts/skeet_icons/` (`waybar.png`, `skins.png`,
  `aim.png`, `notify.png`, `xp.png`, `power.png`, `rage.png`, `visuals.png`, `misc.png`, `players.png`);
  without them the tabs simply have no icons.
- Optional translation refinement: `calc_copy.sh` / `translate_popup.py` call
  `~/.config/hypr/scripts/translate_refine.sh TEXT SRC TGT` if you create one; otherwise the
  offline translation is copied as is.
